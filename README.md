# Поиск лучшего разбиения в дереве решений с нуля

Компактная реализация алгоритма выбора оптимального разбиения для задач бинарной классификации и регрессии. Проект сосредоточен на ключевом вычислительном шаге внутри дерева решений.

## Реализованная функциональность

- генерация кандидатных порогов между соседними различающимися значениями признака;
- вычисление взвешенной неоднородности Джини для бинарной классификации;
- вычисление взвешенной дисперсии дочерних узлов для регрессии;
- исключение порогов, создающих пустой дочерний узел;
- возврат всех кандидатных порогов, значений критерия и лучшего разбиения;
- детерминированный выбор первого минимального порога при равенстве критерия.

## Инструменты

Python, NumPy, pandas.
